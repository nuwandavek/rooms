# Resources

Everything on the Resources tab comes from this file. Each `##` section is a gallery of
`![alt](path)` images. A section named like a room in `home.js` (or tagged `{#room-id}`)
fills that room's photos; `## Floor plan` sets the plan image and its note; any other
section becomes an extra group. Other prose is for people: record sources here.
